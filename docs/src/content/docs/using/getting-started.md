---
title: Join and set up your account
description: Accept an invitation, create or link a Navidrome account, and add your first track.
---

## Accept an invitation

Open the invite link the server administrator sent you and press **Start** in Telegram. Invites work for one person and expire after seven days by default. Ask the administrator for a new one if it has expired or was already used.

Choose a [Navidrome](https://www.navidrome.org/) login when the bot asks. It must contain 3 to 32 characters: Latin letters, digits, dots, hyphens, or underscores. The bot creates the account and shows its password once. Save it before deleting the message.

If you already have an account on this Navidrome server, select **I already have an account**. Send `login password` when prompted. The bot deletes that input message. An account already linked to another participant cannot be linked again by you.

## Link an account later

Open **Settings > Navidrome account > Link**. Use **Link another** if you need to change the linked account.

A regular linked account sees its personal library, the shared library, and separate existing libraries the administrator has granted it. Linking removes access to other participants' personal libraries and libraries that contain all the bot's managed folders. A Navidrome administrator account retains access to every library.

## Add your first track

Send the bot an audio file in your private conversation. Wait for the thumbs-up reaction, then open [Navidrome or your listening app](./listening.md). Navidrome may need a moment to scan the file.

Find the track in **Music > Mine**. From its card, you can request the file or add it to the shared library.

## Change language

Open **Settings > Language**. English and Russian are included. The server administrator can install additional translations.

If you opened the bot without an invite and are not an administrator, it shows the invite-only screen. Contact the server owner for access.
