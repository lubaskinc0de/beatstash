# Contributing to beatstash

Bug reports, fixes, and new music providers are welcome. The full guide lives on the documentation site:

- [Contributing](https://lubaskinc0de.github.io/beatstash/development/contributing/): how to report a problem, prepare a change, add an integration, and edit the docs.
- [Local development](https://lubaskinc0de.github.io/beatstash/development/local/): tools, configuration, and running the checks.

In short: keep a pull request to one problem, cover behavior changes with an end-to-end scenario, and run `just lint` and `just test` before opening it. Remove credentials and private data from any logs you attach.

Contributions are included under the project's [MIT license](LICENSE).
